## 🛠️ Requirements & Execution

### Prerequisites
- Python 3.8+
- NumPy
- Pandas

Install dependencies via pip:
```bash
pip install numpy pandas
```

### Running a Script
Execute any Python practical from the root directory:
```bash
python "Practical 3 - Searching and Sorting/01_linear_search.py"
```
